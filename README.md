# Aurum — VSB Gold

Premium jewelry scroll landing page (React + R3F + GSAP).

## Run

```bash
npm install
npm run dev
```

## Swap in a real pendant GLB

```
public/models/pendant.glb
```

Mesh names auto-detected: `ChainLeft`, `ChainRight`, `Bail`, `Frame`, `Gem`, `Setting`, `Medallion`, `BackPlate`, `Clasp`.
